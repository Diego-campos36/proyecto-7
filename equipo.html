Equipo de desarrollo CareOut

Desarrollo web automotriz moderno

Somos estudiantes del CBT No. 52 enfocados en crear soluciones digitales modernas para el mundo automotriz.

Nuestro objetivo es diseñar una plataforma visualmente atractiva, fácil de usar y optimizada para mejorar la experiencia del usuario.

Este proyecto combina diseño web, programación y trabajo en equipo para desarrollar una página moderna y funcional.

Cada integrante aporta conocimientos en frontend, backend, diseño UI y gestión de contenido.

Buscamos crear una experiencia profesional que refleje esfuerzo, dedicación y aprendizaje tecnológico.
